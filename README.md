# QA Python Project: Тестирование бургерной Stellar Burgers

## Задание 1: Юнит-тесты

### Описание
Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers.

### Реализованные сценарии
Созданы юнит-тесты, покрывающие класс `Burger` с использованием моков и параметризации.

### Тестируемые методы класса Burger

#### 1. `__init__()` - конструктор класса
**Тестовые методы:**
- `test_init_bun_is_none` - проверяет, что при создании объекта булочка равна `None`
- `test_init_ingredients_empty_list` - проверяет, что при создании объекта список ингредиентов пуст

#### 2. `set_buns()` - установка булочки для бургера
**Тестовый метод:**
- `test_set_buns_sets_bun_correctly` - проверяет корректность установки булочки в объекте

#### 3. `add_ingredient()` - добавление ингредиента в бургер
**Тестовые методы:**
- `test_add_ingredient_adds_one_ingredient` - проверяет добавление одного ингредиента (параметризованный тест для разных типов)
- `test_add_ingredient_adds_multiple_ingredients` - проверяет добавление нескольких ингредиентов (параметризованный тест для разного количества)

#### 4. `remove_ingredient()` - удаление ингредиента по индексу
**Тестовый метод:**
- `test_remove_ingredient_removes_by_index` - проверяет удаление ингредиента по указанному индексу

#### 5. `move_ingredient()` - перемещение ингредиента
**Тестовый метод:**
- `test_move_ingredient` - проверяет перемещение ингредиента с одного индекса на другой (параметризованный тест с разными комбинациями)

#### 6. `get_price()` - расчет стоимости бургера
**Тестовый метод:**
- `test_get_price_calculation` - проверяет корректность расчета стоимости с разным количеством ингредиентов (параметризованный тест)

#### 7. `get_receipt()` - формирование чека
**Тестовый метод:**
- `test_get_receipt_exact_format_with_real_objects` - проверяет точный формат чека с реальными объектами

### Запуск автотестов

#### 1. Установка зависимостей
```pip install -r requirements.txt```

#### 2. С подробным выводом
```pytest -v```

#### 3. С покрытием кода class Burger и HTML-отчетом
```pytest --cov=praktikum.burger --cov-report=html```

#### 4. Просмотр отчета о покрытии
```После запуска тестов с покрытием откройте файл htmlcov/index.html в браузере.```
